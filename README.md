# TrendCart Shopping Marketplace

Build a complete, premium, modern e-commerce-style affiliate shopping website called TrendCart.

IMPORTANT:

- The website brand name must be TrendCart everywhere.

- Never use the name RonakFinds.

- The website is an affiliate shopping website, but it must look and feel like a genuine, polished online shopping marketplace.

- It should NOT look like a blog, portfolio, landing page, or basic affiliate website.

- Do not add real Amazon products, real Amazon links, real affiliate links, or API integration yet.

- Use attractive realistic placeholder/demo products only.

- Do not create fake reviews, fake testimonials, fake sales numbers, or misleading claims.

DESIGN STYLE

Create a premium shopping experience inspired by modern e-commerce marketplaces.

Design should be:

- Modern

- Premium

- Clean

- Trustworthy

- Product-focused

- Visually attractive

- Easy to browse

- Mobile-first

- Fully responsive

Use excellent typography, spacing, cards, shadows, subtle animations, polished buttons, attractive product imagery and professional layouts.

The first impression should be:

"This is a real online shopping website."
